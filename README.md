# Al-Mustapha & Maryam — Wedding Website

A premium, cinematic Islamic wedding invitation website.

**Live Site:** [Coming soon]

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- Custom CSS animations
- Google Fonts (Cormorant Garamond, Inter, Amiri)

## Features

- Cinematic envelope opening sequence
- Responsive mobile-first design
- Quranic verses with proper Arabic typography
- Wedding countdown (timezone-aware)
- Photo gallery
- Wedding gifts with copy-to-clipboard
- Share (native + WhatsApp)
- Calendar integration (Google Calendar + .ics)
- Background music with mute toggle
- Reduced motion support

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Push to `main` branch — Vercel auto-deploys.
